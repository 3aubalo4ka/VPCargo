# VPCargo

Простой PHP + MySQL проект для кабинета клиента и админ-панели.

## Установка

1. Создайте БД и импортируйте `database/vpcargo.sql`.
2. Настройте доступ к БД в `config.php`.
3. Для XLSX импорта установите зависимости:

```bash
composer install
```
